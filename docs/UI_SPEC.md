# Wacu · UI 设计图落地规范（2026-10-10）

本规范对应用户选定的两页《Wacu 桌面用量监控组件 · UI 设计图》：
第 1 页为胶囊、展开详情和设置；第 2 页为组件规格、交互状态、尺寸与色板。
**以原生窗口行为、清晰度和完整显示优先，不按插图强行填充 6 个不存在的平台。**

## 设计结构

| 设计图 | 实现 | 当前状态 |
| --- | --- | --- |
| 主胶囊：黑色竖向窄胶囊 | `CapsuleWindow`，透明窗口 + 深色圆角渐变面板 | 已实现 |
| 常驻模式 | 保留已存位置，置顶，可按住顶部拖动 | 已实现 |
| 点击弹出模式 | 系统托盘弹出，失焦自动收起 | 已实现；托盘真实手动操作待最终验收 |
| 点击平台，右侧/左侧就近展开 | `DetailWindow` 初始紧凑快览模式，使用屏幕可用工作区定位 | 已实现 |
| 详细用量面板 | 快览底部点击“查看详细用量”转为完整详情 | 已实现 |
| 使用趋势图 | 16 个示意柱，支持“今日／7天／30天”演示切换 | 已实现，**非真实记录** |
| 设置面板 | 常规／服务管理／外观／行为／关于，左侧导航、右侧内容 | 已实现 |
| 组件与交互规范 | 进度环、模式按钮、Hover、切换状态、滑杆 | 已实现核心状态 |
| 颜色与动画 Tokens | 深灰中性色，服务独立强调色，150–420ms 过渡 | 已实现 |

## 实际尺寸（Slint 逻辑像素，DPI 会影响物理像素）

- 胶囊窗口：宽 **76px**；高 `96 + 76 × max(1, 已启用服务数)`，默认 3 项为 324px。
- 内部胶囊：外边留 5px，圆角半径 34px；每个服务项宽 56px、高 76px。
- 进度环：直径约 44px，深灰轨道、独立服务高亮色、中心品牌标记；数字 13px。
- 底部模式/设置：30px 圆形触点，保留操作区与 Demo 标记。
- 快览详情：**302 × 365px**，紧贴胶囊旁边显示，不遮挡主体。
- 完整详情：**302 × 596px**，保持既有窗口宽度，展开图表和切换栏。
- 设置窗口：**608 × 490px**，左侧导航 154px，右侧分区内容。

相比设计图里为了同时容纳六项服务所写的 48×360px，本版对 **只有三个真实平台条目** 的产品做了可读性适配；缩窄到 48px 会损害进度环、文字及鼠标点击范围。

## 配色和动效

| 用途 | 色值 |
| --- | --- |
| 主胶囊背景 | `#101215` 到 `#202327` |
| 面板背景 | `#171A1E` / `#202429` |
| 轨道 | `#30363E` |
| Codex | `#8ED8B6` |
| Claude Code | `#E69F81` |
| WorkBuddy | `#A49AEE` |
| 设置选中蓝 | `#2885F2` |

- 胶囊出现/收起：**185ms** 淡入 + 轻微位置位移（设置可以关闭动画）。
- 进度环 Hover：**170ms** 尺寸与边框过渡，条目背景 **160ms**。
- 底部动作：**150ms** 状态过渡。
- 详情条：**420ms** 宽度过渡；图表示意柱：**280ms** 高度变化。
- 不使用常驻 60 FPS 循环或持续旋转效果；Rust 服务采集未接入。

## 实现限制和不伪造原则

1. 设计图展示了 6 种彩色环，但当前项目仅定义 Codex、Claude Code 和 WorkBuddy 三个服务。
2. 所有用量数字、趋势柱状图均是**带明确文字标记的演示内容**；不会以图表颜色或动画冒充真实 API 数据。
3. “开机启动”在设置中明确显示“规划中”，没有无法工作的假开关。
4. “行为”页提供动画开关，“外观”页提供胶囊透明度 65%–100%；服务可见性及显示模式继续使用原有持久化配置。
5. Windows 通知区不等同于 Windows 小组件系统入口；不会修改系统 Explorer。
6. 字体在不同 Windows 版本可能略有差异，旧显卡、DPI、自动隐藏任务栏仍需现场测试。

## Debug 可重复截图检查

仅 Debug 构建可用以下测试入口，不需要模拟鼠标、不改动真实用户配置。

```powershell
$env:WACU_QA_VIEW = "capsule"   # 或 quick / detail / settings
cargo run
```

程序开始后会将当前选定界面的 Slint 原生帧快照保存到
`target/wacu-qa-<view>.png`，文件位于已忽略的 Cargo 构建目录。
完成检查后可清理 `$env:WACU_QA_VIEW`。Release 不提供该入口。

**后续需要真实鼠标验收**：托盘左键、键盘焦点、菜单定位、详情切换后的自动收起、全平台关闭状态、跨多屏位置等。
