# Wacu · Windows 原生界面验收

日期：2026-10-10 · 范围：UI 原型和窗口管理，不涉及真实用量采集。

## 测试环境

- Windows 11 双显示器，每块显示器 1920×1080；桌面工作区高度 1032。
- Node.js / Vite 提供开发页面，Rust Debug 可执行程序提供 Tauri 原生窗口。
- Debug 可执行程序 **必须在 Vite 开发服务器运行时启动**。发布构建则内嵌前端资源。
- 命令执行器可能回收它启动的 GUI 子进程；测试需由同一会话托管应用运行，不能把工具清理子进程误判成应用主动退出。

## 本轮修复

1. 默认 Popup 模式启动时隐藏窗口，不再启动就挡住桌面。
2. 托盘左键点击使用触发位置决定胶囊弹出位置，不再硬编码主屏右下角。
3. 使用 Monitor 工作区进行边界约束，适配任务栏占用和负坐标副屏。
4. 常驻模式保存物理坐标，模式切换后恢复；设置页提供重置位置入口。
5. 详情面板随胶囊定位并限制在对应显示器工作区内。
6. 暂不引入隐藏窗口动态尺寸调整，待独立测试后再实现。

## 运行与定位测试

```powershell
npm install
npm run tauri dev
```

需要单独验证定位模块时，Windows 下可执行：

```powershell
rustc --edition 2024 --test src-tauri/src/placement.rs -o $env:TEMP\wacu-placement-tests.exe
& $env:TEMP\wacu-placement-tests.exe
```

运行时配置文件位于 Tauri 的 `app_config_dir/display-mode.json`，只保存显示模式与常驻坐标，不保存账户令牌。
