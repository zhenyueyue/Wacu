# Wacu · 产品规范 v0.2

## 定位

Wacu（古英语，守望/保持警醒）是一款低打扰的 Windows AI 额度监控软件，面向同时使用多款 AI 编程工具的个人开发者。

## 确定的产品决策

1. **双模式**：默认点击任务栏入口后弹出纵向胶囊，也可切换常驻悬浮。两种模式在设置内随时切换。
2. **纵向胶囊外观**：深色无边框大圆角；服务 Logo / 识别标记居中，外围环形进度；下方显示剩余百分比。
3. **按需展开**：点击平台可看到窗口额度、重置时间、余额信息，胶囊本身只承载摘要。
4. **低打扰**：不干扰 AI 工具，不发送测试模型请求，不在背景频繁读取用量。
5. **可靠性优先**：未获得真实额度时必须显示无数据或过期状态，不得用零、满额或模拟数据冒充真实结果。

## 第一阶段（当前）

- [x] Rust + Slint 原生工程，已取代 Tauri/React。
- [x] Windows 托盘入口与右键菜单。
- [x] 弹出 / 常驻双模式切换、持久化。
- [x] 参考图风格的胶囊进度环与详情、设置。
- [x] 模拟数据明确标注。
- [ ] 真正嵌入/占据任务栏天气式入口（Windows 未公开相关扩展能力，需单独论证）。
- [ ] Slint 版本双显示器完整交互验收（胶囊点击、详情、设置、模式切换及副屏位置记忆）。
- [ ] Windows DPI、Explorer 重启、任务栏自动隐藏、长期驻留专项验收。
- [x] 常驻位置记忆、工作区约束、重置位置。
- [ ] 自动吸边及拔插显示器的异常场景验证。
- [x] 胶囊高度按启用的服务数量动态调整（含全部关闭的空状态）。

## 第二阶段

Codex 真实额度采集 → Claude Code → WorkBuddy 官方授权可行性验证。每个平台必须单独适配和测试。订阅配额与 API Token 账单严格区分。

## 第三阶段

自动更新与缓存、限流退避、凭据安全、通知提醒、开机启动、历史记录、可拓展适配器系统。

## 验收要求

- 未连接账号仍能预览胶囊，但处处明确“演示数据”。
- 托盘和设置任一位置切换模式都能生效，重启保持选择。
- Popup 失焦隐藏；Pinned 失焦不隐藏，顶部可拖动。
- 胶囊点击进入详情、设置可用；系统右键菜单可完全退出程序。
- UI 不操作现有的 Codex / Claude / WorkBuddy 凭据。
