# Wacu · 两页设计图落地规范

日期：2026-10-11。对应用户提供的桌面用量监控组件设计图：胶囊、详情、设置，以及组件、状态、尺寸和颜色规范。

## 新入口：Mini ↔ 纵向胶囊

Wacu 正式版不使用 Windows 系统托盘、Explorer 注入或系统 Widgets 扩展。程序启动仅显示独立的 66×66px 深色圆形 Mini，中央使用现有品牌头像。左键 Mini 立即展开用量胶囊，左键胶囊顶部头像立即收起；左键松开直接启动切换，不等待单双击判定。双击入口已移除。右键 Mini 或胶囊任意位置弹出 Windows 原生菜单，仅有“设置”“退出”；选择设置显示设置窗口，选择退出结束应用，点击菜单外或 Esc 取消。超过 7px 才判为拖动，拖动不触发切换。

两个窗口交替显示，不会持续绘制两个入口。Mini 与胶囊的桌面坐标完全独立：`mini_position` 控制 Mini（首次默认屏幕右下角），`saved_position` 控制纵向胶囊（首次默认同屏右侧中间）。点击切换时读取各自坐标，不通过中心点互相换算；拖动只改变被拖动窗口的坐标。跨屏情况下已保存的位置也按各自屏幕工作区限制。设置“行为”页提供分别恢复 Mini、胶囊默认位置。完整详情仍在胶囊旁，折叠时关闭详情。三档大小只影响胶囊，不改变 Mini 大小。

切换使用“能量胶囊”动效。Mini 在 100ms 内缩至 72%、轻旋 12°并淡出；返回时用 180ms 贝塞尔曲线轻微回弹，外圈出现一次青绿色脉冲。胶囊以顶部 56px 圆形为起点，用 180ms 舒展开完整外壳，Logo 上移 8px，服务环按当前可见顺序依次浮现并上移 14px；收起用 140ms 反向聚拢。边框短暂亮起 `#A3F5D4`，两侧窄微光沿展开方向移动，完成后消失。内容采用固定尺寸布局和裁切，文字、圆环不会被纵向拉伸。原生窗口大小和桌面坐标保持稳定。

交接时两窗短暂重叠绘制，退出动画完成后隐藏原窗口。共享代次标记取消过时的显示／隐藏定时器，允许途中反向切换；退场窗口停止接收点击，服务在展开进度超过 85% 后响应。关闭“显示动画”时同步切换，无交接延时、脉冲或持续帧循环。右键菜单使用 Slint ContextMenuArea，由 Windows 原生菜单处理显示、键盘选择和取消。

正式版仅常驻 Mini，**不实例化系统托盘组件**。右键 Mini 打开设置／退出菜单，不触发展开；设置“关于 → 退出 Wacu”也保留退出入口。纯 Mini 空闲的 Release 实测约 67.9 MB 私有内存（6 秒 CPU 样本 0ms）。实际窗口截图：[Mini 悬浮入口](screenshots/mini.png)。以下胶囊、详情、组件和历史模式规范仍作为界面实现资料保留。

## 本轮实现

| 设计要求 | 程序实现 |
| --- | --- |
| 黑色窄胶囊、圆形角色、百分比、右键菜单进入设置 | 默认标准档 72px 主体、56px 进度环、32px 双眼角色、15px 数字；三档大小可选，底部无齿轮 |
| 点击后在侧面展开，不覆盖胶囊 | 优先右侧，空间不足时左侧；保持屏幕工作区内；蓝色箭头指向面板 |
| 快览：大百分比、进度条、三行信息、详情按钮 | 已用百分比与次数、今日用量、剩余额度、重置时间 |
| 完整详情：时间筛选、柱状图、官网入口 | 今日／7天／30天／全部，24 根演示柱、网格和五个刻度；打开默认浏览器 |
| 设置：左导航、右内容、底部链接 | 常规／服务管理／外观／行为／关于，圆角深色窗口与 Fluent 控件 |
| 常规设置 | 开机启动、常驻显示、贴边隐藏、显示动画、透明度、左右位置、简体中文、检查更新入口 |
| 悬停、选中、按下 | 背景微亮、蓝色环绕光晕和箭头、圆环缩小及降低亮度 |
| 动画与透明度 | Mini／胶囊交接 100–180ms 贝塞尔曲线，其余微动效 100–200ms；动画开关统一控制；透明度保留 65%–100% |

当前只有 Claude Code、Codex、WorkBuddy 三项服务，按原图橙／绿／紫顺序排列；开关仍使用稳定服务 ID，不因排序和过滤错配。没有为了凑满六项添加不存在的服务。

按用户确认保留三项服务，已校准快览、详情、设置的纵横比例和内部留白。面板与卡片采用石墨色渐变；选中胶囊增加整圈蓝色边框、蓝色光晕，箭头对齐服务圆环中心；快览按钮恢复左图标与右箭头，官网按钮将外链图标放在文字旁。下拉框保留原生输入行为；透明度滑杆保留原生键盘、焦点与无障碍处理，鼠标使用小手命中区域，绘制表面匹配设计图。

本轮按“除了悬浮面板都小一点”的反馈保留胶囊三档尺寸，详情恢复 1.0 倍排版，设置使用独立尺寸与更紧凑的行距。

按最新外观反馈恢复胶囊外形，顶部使用用户提供的 `docs/logo.png`，原始图保留不变；`scripts/prepare-logo.py` 生成带平滑透明圆形边缘的 2x PNG，界面使用平滑采样，避免大图直接缩小造成锯齿。两种模式均可从 Logo 区拖动。进度环与背景轨道使用相同路径坐标，新紧凑／标准／宽松线宽为 4／4.5／5px，背景色 `#3B3E43`。Logo 与服务区使用 16／18／20px 间隔；底部齿轮及整行空白已移除。上下端内边距均为 16px。

悬浮窗主体使用纯色 `#1B1C1F`，彩色角色同样使用纯色；外框圆角为主体宽度的一半。

胶囊百分比采用 Windows 系统字体 Bahnschrift，字重 500；新版紧凑／标准／宽松字号为 14／15／16px。数字行相对服务项顶部位于 45／51／57px，保持各档圆环和百分比间距一致，服务项高度为 70／77／84px。

圆环使用同服务色的连续高斯光晕，替换原先七层描边的生硬过渡；全环淡光、进度弧稍亮，弧线两端按距离柔和衰减。Rust 在服务模型创建时生成 2x 透明像素图，Slint 平滑采样并随圆环缩放；没有逐帧模糊计算。灰色轨道与彩色进度弧仍为清晰的原生路径。

同一品牌 Logo 用于 EXE 文件、三个窗口与系统托盘。`scripts/prepare-logo.py` 从保留的原图生成圆形透明 PNG 与十档 ICO（16／20／24／32／40／48／64／96／128／256px），构建脚本将 ICO 嵌入 Windows 资源。`python scripts/check-icon.py` 验证 Release EXE 中十档图标的实际字节与源 ICO 一致。

弹出与常驻共用保存的桌面位置，首次使用采用左／右侧居中位置；点击托盘仅控制显示，不再以鼠标或托盘坐标作为锚点。切换模式时立即保存可见位置，贴边隐藏时使用隐藏前的位置；左右位置和重置也适用于已显示的弹出胶囊。

启动先显示胶囊，弹出模式约 3 秒后自动淡出，常驻模式保持显示。悬停或查看详情时暂缓收起；点击托盘、拖动 Logo、打开详情或设置会结束启动预览，后续使用正常的弹出收起规则。拖动期间暂停自动隐藏，松开后即时保存坐标，并重新计算交互缓冲时间。

Logo、胶囊顶端、设置标题栏与透明度滑杆统一使用 `pointer` 小手光标。拖动区使用明确的局部坐标和尺寸，不覆盖服务或按钮。原生窗口拖动在鼠标按下事件处理完后启动，结束时向 Slint 补发鼠标释放和位置事件，清除原生拖动吞掉鼠标抬起后残留的命中捕获，避免后续点击继续触发拖动。

彩色进度弧使用原生 `stroke-line-cap: round`，两端半圆收尾。路径统一采用 56 × 56 显式 viewbox，去除之前用于占位的零长度线段，避免圆头在边角生成杂点；0% 不画彩色弧，100% 画闭合圆环。

## 功能边界

- 所有额度与图表仍是演示数据，详情标题旁和服务管理／关于页明确标识。Claude 示例为 240 / 1,000 次，已用 24%，剩余 760 次；三个服务均校验已用 + 剩余 = 总额。
- 开机启动仅在用户操作开关时修改当前用户 Run 注册表项，默认关闭；状态读取匹配当前程序路径的注册表项。Windows 实际重新登录启动尚未验收。
- 常驻模式靠近边缘可收起，保留 6px 逻辑触点；移入后恢复并保留 800ms 进入时间。配置只保存正常位置，隐藏坐标不会写入配置；算法包含负坐标副屏及 DPI 换算检查。
- 详情保持焦点或鼠标位于详情内时，弹出胶囊不提前收起。关闭当前选中服务时同步关闭详情并清除选中状态。
- 语言目前仅支持简体中文。版本按钮查看 GitHub Releases，不显示虚假的“已是最新版本”，不自动下载或安装。
- 设置页错误提示用于注册表、偏好保存及浏览器打开失败。真实登录账户、自动更新和长时间运行仍属后续范围。

## 按钮与头像交互微动效（2026-10-11）

- **设置入口**：胶囊底部齿轮及空白占位已经删除。右键 Mini 或胶囊，在菜单选择“设置”；左键头像立即展开／收起。
- **顶部 Wacu 头像**：悬停仅放大约 2%，按住拖动缩至 97%，配合低透明度暖绿色高亮；原生拖动结束后约 125ms 恢复，并遵从“显示动画”开关。
- **服务头像点击**：不再眨眼、不下沉、不让进度环整体缩放，也不出现覆盖整行的灰色椭圆。保持圆环和头像尺寸、位置不变，按下只调整环亮度、头像底色和极淡的光晕，约 120ms 恢复；无常驻动画循环。
- **即时切换**：不再判定双击或延迟单击；左键松开直接切换，超过拖动阈值后松开不触发切换。右键只打开菜单。
- **验收截图**：[胶囊](screenshots/capsule.png)、[头像拖动状态](screenshots/capsule-logo-drag.png) 和 [服务头像按下态](screenshots/capsule-service-pressed.png) 均来自 Slint 原生渲染。

## 详情窗口开关动效（2026-10-11）

- 点击胶囊中的服务时：详情自身从透明状态开始，在 **175ms** 内淡入，面板同时从右下方约 6×5 逻辑像素的位置轻微移回最终锚点；不对窗口内容单独做夸张缩放。
- 点击关闭按钮或失焦关闭时：先反向淡出和轻微位移，动画结束后再真正隐藏窗口；不会使用直接 `hide()` 切断动画。
- 快速关闭再打开：用生命周期序号取消先前排队的隐藏回调，不会将刚打开的详情误关掉。
- “显示动画”关闭时：显示和隐藏立即生效，没有人为等待。
- **拖动例外**：依照已确认的方案，开始拖动胶囊时详情仍立即消失，松手之后从新位置淡入，不会在拖动过程中留下残影。
- Debug 原生验收不仅测试窗口可见状态和快速重开，还比较动画开始/结束时详情中央像素 Alpha，验证确实发生了渐变。

## 用量详情与主胶囊拖动（2026-10-11）

- 点击服务后详情贴在胶囊旁边；**不再显示蓝色三角箭头**，避免装饰遮挡和视觉突兀。
- 拖动主胶囊的顶部区域或 Wacu 头像时，如详情已打开，会**立即隐藏详情**；Windows 原生窗口拖动结束（释放鼠标）后，使用新胶囊坐标和当前屏幕工作区重新定位，再恢复显示**同一个详情窗口与服务选中状态**。
- 没有打开详情时拖动不会额外打开窗口；不需要子类化 Win32 窗口消息，也不增加任何持续位置同步计时器。
- Debug 模式的 `WACU_QA_DRAG_DETAIL=1` 会验证详情隐藏、胶囊坐标变化、同一服务的详情恢复和新锚点位置。该检查已纳入 `scripts/capture-ui.ps1` 的快览测试项。它不替代最终真实鼠标的人机测试。

## 可重复截图

```powershell
python scripts\prepare-logo.py     # 更换 docs/logo.png 后重建小尺寸资源，需要 Pillow
cargo build
.\scripts\capture-ui.ps1             # 17 张外观快照 + 隔离配置的控件输入检查
.\scripts\capture-ui.ps1 -Archive    # 将同一批快照更新到 docs/screenshots
python scripts\ui-overview.py        # 生成总览，需要 Pillow
```

每个预览进程采用默认测试配置，生成截图后退出，不保存胶囊位置、不修改用户设置或启动项。环境变量只设置在子进程上。预览窗口不注册系统托盘图标；Release 不提供这些调试入口。
