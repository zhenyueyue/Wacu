# Wacu · UI 设计图落地规范（2026-10-10）

本规范对应用户选定的两页《Wacu 桌面用量监控组件 · UI 设计图》：
第 1 页为胶囊、展开详情和设置；第 2 页为组件规格、交互状态、尺寸与色板。
**以原生窗口行为、清晰度和完整显示优先，不按插图强行填充 6 个不存在的平台。**

## 设计结构

| 设计图 | 实现 | 当前状态 |
| --- | --- | --- |

## 实际尺寸（Slint 逻辑像素，DPI 会影响物理像素）

- 胶囊窗口：宽 **62px**；高 `80 + 65 × max(1, 已启用服务数)`，默认 3 项为 275px。
- 内部胶囊：外边留 5px，圆角半径 27px；每个服务项宽 48px、高 65px。
- 进度环：直径约 40px，深灰轨道、独立服务高亮色、中心品牌标记；数字 12px。
- 底部设置按钮：30px 圆形触点，保留 Demo 标记。模式切换在设置页和托盘菜单中完成。
- 快览详情：**302 × 399px**，紧贴胶囊旁边显示，不遮挡主体。
- 完整详情：**302 × 586px**，保持既有窗口宽度，展开图表和切换栏。
- 设置窗口：**500 × 574px**，左侧导航 140px，右侧分区内容。

设计图的胶囊约为 48×360px（六项服务）。当前只有三项服务，采用 62px 视窗（其中内容主体约 52px）保留清晰的数字与触控尺寸；去掉多余的顶部大标识与底部双按钮。

- 胶囊出现/收起：**185ms** 淡入 + 轻微位置位移（设置可以关闭动画）。
- 进度环 Hover：**170ms** 尺寸与边框过渡，条目背景 **160ms**。

- 不使用常驻 60 FPS 循环或持续旋转效果；Rust 服务采集未接入。

## 实现限制和不伪造原则

1. 设计图展示了 6 种彩色环，但当前项目仅定义 Codex、Claude Code 和 WorkBuddy 三个服务。
2. 所有用量数字、趋势柱状图均是**带明确文字标记的演示内容**；不会以图表颜色或动画冒充真实 API 数据。
3. “开机启动”在设置中明确显示“规划中”，没有无法工作的假开关。
4. “常规”和“行为”页提供相同的动画开关，“外观”页提供胶囊透明度 65%–100%；服务可见性及显示模式继续使用原有持久化配置。
5. Windows 通知区不等同于 Windows 小组件系统入口；不会修改系统 Explorer。
6. 字体在不同 Windows 版本可能略有差异，旧显卡、DPI、自动隐藏任务栏仍需现场测试。

## 本轮截图对比与排版修复

本次不是只核对窗口能否显示，而是逐屏对照已选中的两页设计图；发现并修正了以下布局根因：

1. **详情列表固定三列**：每行图标从 x=0px 开始、字段名称 x=33px、数值 x=110px，三个 Text 共用 32px 高度和垂直居中，数值统一右对齐。不会再因文本长度不同而把数值顶向中间。
2. **详情百分比行**：大数字锁定左侧，右侧单位/状态锁定右边界；图表三个时间刻度分别固定在左、中、右。
3. **设置导航**：五个菜单项均为 44px 高，图标 x=11px、名称 x=46px，固定垂直中心，选中线独立于文字排版。
4. **设置项**：普通开关、规划项共用 70px 行高与两条文字基线（标题 y=10px、说明 y=35px），开关和规划状态占相同的右侧区域。
5. **外观透明度**：滑杆使用独立的固定宽度区，数值强制位于右端，而非被组件最小宽度挤在滑块旁。
6. **Slint 伸缩异常**：为直接处于 VerticalLayout 的说明文字指定固定高度，避免文字高度被自动拉伸产生大块无意义留白。
7. **胶囊贴近设计图**：由 76px 缩窄为 62px（黑色胶囊主体约 52px），简化顶部标识和底部按钮。

## Debug 可重复截图检查

仅 Debug 构建可用以下测试入口，不需要模拟鼠标、不改动真实用户配置。

```powershell
$env:WACU_QA_VIEW = "capsule"   # 或 quick / detail / settings
cargo run
```

程序开始后会将当前选定界面的 Slint 原生帧快照保存到
`target/wacu-qa-<view>.png`，文件位于已忽略的 Cargo 构建目录。
如需检查设置分类，可额外设置 `$env:WACU_QA_PAGE = "0"` 到 `"4"`（依次为常规、服务管理、外观、行为、关于）；重新启动后生成该分类的设置截图。完成检查后可清理这两个环境变量。Release 不提供该入口。

**后续需要真实鼠标验收**：托盘左键、键盘焦点、菜单定位、详情切换后的自动收起、全平台关闭状态、跨多屏位置等。
